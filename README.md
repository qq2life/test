# Детекция и сегментация планктонных организмов (YOLO26n, Faster R-CNN, GrabCut, SAM 2)

Лабораторная работа с **фактически выполненными** экспериментами на 12 исходных микроскопических снимках, 4 аугментациями для каждой детекционной модели и сравнением 11 пар сегментационных масок. Исходные модели не дообучались; все детекторы используют предобученные веса (COCO), SAM 2.1 — предобученные веса Meta.

> **Данные:** [папка преподавателя](https://drive.google.com/drive/folders/1LT2NdDSULHiW3FwzT63ewgVO3pwRRhOW?usp=sharing). Из-за частичного скачивания проанализировано 86 изображений из набора, 12 отобрано для детекции. Исходные изображения в репозиторий не включены. Разрешение на публикацию изображений и визуализаций **не установлено** — см. `PUBLICATION_RIGHTS.md`.

## Итоги эксперимента

| Детекция | Снимки/прогоны | Среднее боксов/снимок | Время/снимок (CPU) |
|---|---:|---:|---:|
| YOLO26n — оригиналы | 12 | 2,917 | 0,308 с |
| YOLO26n — 4 аугментации | 48 | 2,688 | 0,307 с |
| Faster R-CNN — оригиналы | 12 | 8,500 | 13,387 с |
| Faster R-CNN — 4 аугментации | 48 | 9,313 | 12,907 с |

На исходных снимках YOLO оказался **в 43,4 раза быстрее** Faster R-CNN; у Faster R-CNN видны многочисленные пересекающиеся боксы на одной особи. **Большее число боксов не означает более высокую точность**.

| Сегментация | Маски (общие детекторные боксы) | Время/маску (CPU, включая embedding SAM2) |
|---|---:|---:|
| GrabCut | 11 | 4,605 с |
| SAM 2.1 Hiera Tiny | 11 | 3,852 с |

Межметодное IoU масок: **0,761** (среднее). Это **сходство двух предсказаний, а не качество относительно ground truth**.

## Содержимое открытой версии репозитория

- `plankton_detection_segmentation.ipynb` — выполненный ноутбук с кодом и текстовыми результатами; встроенные фотографии удалены из публичной копии.
- `requirements.txt` — зависимости, а также версии среды из `results/metrics/run_metadata.json`.
- `results/metrics/` — структурированные результаты CSV/JSON/JSONL, 4 эксперимента по детекции и сравнение масок.
- `FINAL_REPORT.md` — подробный аналитический отчёт по фактически выполненному прогону.
- `PUBLICATION_RIGHTS.md` — объяснение, почему визуальные результаты не публикуются без разрешения правообладателя.

**Не включены:** исходные изображения и визуализации с их пикселями (галереи, bounding boxes, маски-оверлеи). Они находятся в отдельном архиве результатов для передачи преподавателю по разрешённому каналу. Без них публичный репозиторий не полностью удовлетворяет требованию задания о публикации визуализаций.

## Воспроизведение в Google Colab

1. Откройте `plankton_detection_segmentation.ipynb` в [Google Colab](https://colab.research.google.com/) и при наличии доступа выберите **Runtime → Change runtime type → T4 GPU**. **Фактический сохранённый прогон был на CPU**.
2. Выполните все ячейки по порядку. При первой установке потребуются интернет и загрузка весов. Для SAM2 при отсутствии подходящей CUDA-сборки используется `SAM2_BUILD_CUDA=0`.
3. Ноутбук автоматически скачивает данные через `gdown`; при ошибках в Google Drive следует скачать изображения вручную и положить их в `data/`, установив `AUTO_DOWNLOAD=False` в конфигурации. Обращайте внимание, что публичная папка может скачаться не полностью.
4. При повторном запуске не удаляйте `results/`: в текущем репозитории уже лежат сохранённые результаты выполненного прогона и таблицы.

### Локальное окружение

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter lab plankton_detection_segmentation.ipynb
```

Для CPU или GPU установите совместимые версии PyTorch/torchvision, следуя [инструкции PyTorch](https://pytorch.org/get-started/locally/).

## Ограничения

- Модели детекции обучались на COCO; классы `bird`, `person`, `kite` и пр. в результатах **не** означают вид планктона.
- Ни mAP, ни Precision/Recall **не вычислялись** из-за отсутствия эталонной разметки.
- Нет подтверждения разрешения правообладателя на повторную публикацию изображений/overlays. Вы должны проверить права **до** публичной публикации данного полного архива.
- Результаты относятся только к 12 выбранным изображениям, а не ко всему датасету.

## Публикация и права

Этот репозиторий содержит только файлы, которые не воспроизводят пиксели чужих микроскопических снимков. Републикация визуальных производных требует соответствующего разрешения правообладателя. При получении разрешения можно добавить полную папку `results/` из локального архива.
